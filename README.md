# FUTURE_CS_02 – Phishing Email Detection & Awareness System

**Future Interns | Cyber Security Internship | Task 2**

## Project Overview
This project demonstrates how phishing emails can be identified through suspicious sender details, deceptive subject lines, urgent language and requests for sensitive information.

## Objectives
- Understand common phishing techniques.
- Identify suspicious email characteristics.
- Classify simulated email samples.
- Promote safe email practices.
- Develop cybersecurity awareness.

## Project Structure
- report/ – Final project report (PDF)
- dataset/ – Simulated email samples (CSV)
- analysis/ – Email sample analysis
- references/ – Research and awareness sources
- evidence/ – Project screenshots

## Dataset
The project uses five fictional email examples for educational analysis.

| Sample | Classification |
|---|---|
| E01 | Safe-style control |
| E02 | Suspicious |

| E04 | Phishing |
| E05 | Phishing |

## Methodology
The samples were reviewed based on sender information, subject lines, message content, urgency and requests for sensitive information.

## Important Limitations
All email samples are fictional training examples. No real emails, email headers, live URLs, attachments, SPF, DKIM or DMARC records were tested. Classifications are educational assessments, not results from a live detection engine.

## Prevention Guidelines
- Never share passwords or OTPs through email.
- Verify unexpected requests independently.
- Avoid suspicious links and attachments.
- Use official websites and applications.
- Report suspected phishing emails.
